# 稳盈管家 知识库

## 一、资产配置核心原则

### 金字塔配置模型
```
          🟡 高风险 10-20%
         /  Meme币、新币、杠杆
        /━━━━━━━━━━━━━━━━━━
       /   🟠 中风险 20-30%
      /    主流币、DeFi LP、流动性挖矿
     /━━━━━━━━━━━━━━━━━━━━━━━━
    /      🟢 低风险 30-40%
   /       ETH/BTC、流动性质押、AAVE借贷
  /━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 /          🔵 安全垫 ≥20%
/           稳定币（USDC/USDT/DAI）
```

### 仓位分配标准
| 用户类型 | 安全垫 | 低风险 | 中风险 | 高风险 |
|----------|--------|--------|--------|--------|
| 保守型 | 40% | 40% | 15% | 5% |
| 均衡型 | 25% | 35% | 25% | 15% |
| 进取型 | 20% | 25% | 30% | 25% |

### 分散化铁律
- 单币不超过总仓位的 20%
- 同一赛道（如 Meme、DeFi、L2）不超过 30%
- 同一链生态不超过 40%
- 稳定币永远 ≥ 20%（熊市 ≥ 50%）

## 二、DeFi 理财产品分级

### 🟢 低风险（本金安全优先）
- **AAVE V3 借贷**：USDC/USDT 存款，APY 2-5%，老牌协议，审计完善
- **Lido 质押**：ETH 流动性质押，APY 2-4%，市场最大，TVL $170亿+
- **MakerDAO DSR**：DAI 存款利率，受 Maker 治理控制
- **适合**：大额闲钱、保守型用户

### 🟡 中风险（收益增强）
- **ether.fi / Renzo**：ETH 再质押，APY 3-8%，额外协议风险
- **PancakeSwap / Uniswap LP**：主流币对做市，APY 5-30%，无常损失风险
- **Pendle**：收益代币化，APY 5-50%，需理解到期机制
- **适合**：有一定 DeFi 经验的用户

### 🔴 高风险（激进收益）
- **Meme 币 LP**：极高性能但无常损失巨大
- **新协议挖矿**：高 APY 但协议风险未知
- **杠杆收益**：杠杆质押/借贷，放大收益也放大亏损
- **适合**：只用利润参与，不动本金

## 三、市场周期配置策略

### 牛市
- 稳定币 20% → 逐步减仓锁定利润
- 加大低风险配置（ETH/BTC 定投）
- 中风险可提升到 30%
- 每涨 30% 提利润，用利润追高风险

### 熊市
- 稳定币提升到 50%+
- 低风险为主（借贷收息 + 定投抄底）
- 中高风险降到 10% 以下
- 分批定投，不做一次性重仓

### 震荡市
- 稳定币 30%
- 低风险 40%（吃息为主）
- 中风险 20%（做 LP 收手续费）
- 高风险 10%（快速进出）

## 四、风险识别清单

### 持仓健康度检查
| 指标 | 健康 | 警告 | 危险 |
|------|------|------|------|
| 稳定币占比 | >20% | 10-20% | <10% |
| 单币占比 | <15% | 15-30% | >30% |
| 前3持仓占比 | <50% | 50-70% | >70% |
| 风险代币数 | 0 | 1-2 | ≥3 |
| Meme占比 | <10% | 10-25% | >25% |

### 协议风险评估
- TVL < $10M → 谨慎
- 未审计 → 谨慎
- 成立 < 3 个月 → 谨慎
- 匿名团队 → 谨慎
- 有被黑历史 → 避免

## 五、回答指南

### 用户问"有什么理财产品"
→ 列出 DeFi 产品，按 APY 排序，标注风险等级
→ 问用户风险偏好（保守/均衡/进取）
→ 推荐 2-3 个最适合的

### 用户问"帮我看看配置"
→ 先算总资产
→ 再算各币占比、稳定币占比
→ 标出健康/警告/危险指标
→ 给 1-2 条具体调整建议

### 用户问"现在该投什么"
→ 先看市况（牛市/熊市/震荡）
→ 按用户风险偏好推荐配置比例
→ 给具体产品名称和 APY
→ 永远不替用户做决定

### 用户问"这个协议安全吗"
→ 查 TVL、审计状态、成立时间
→ 给安全评级
→ 明确告知风险点
