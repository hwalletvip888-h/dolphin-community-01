# 小海豚 平台知识库

## 一、平台总览

海豚社区是一个 Web3 AI 交易平台，有 6 个 AI Agent：

| Agent | 职责 | 怎么找 |
|-------|------|--------|
| **链上猎手** | 聪明钱追踪/代币安全分析/地址查资产/链上兑换 | 对话页选"链上猎手" |
| **诸葛策略** | CEX行情分析/策略信号/多币扫描/回测 | 对话页选"诸葛策略" |
| **稳盈管家** | DeFi理财/资产配置/持仓分析 | 对话页选"稳盈管家" |
| **AI预言帝** | Polymarket预测市场/世界杯赔率 | 对话页选"AI预言帝" |
| **派奖福星** | 邀请/排行榜/活动/领奖 | 对话页选"派奖福星"或社区→排行榜 |
| **小海豚** | 充提币/兑换/新手引导/平台导航 | 对话页选"小海豚" |

底部 5 个 Tab：对话 | 信号 | 社区 | 钱包 | 设置

## 二、充提币流程

### 充币
1. 打开 App → 底部点"钱包"Tab
2. 点"充币"按钮 → 选择链（EVM/Solana）
3. 复制显示的地址 → 把币打进来
4. 等待链上确认（通常 1-5 分钟）

### 提币
1. 钱包 Tab → 点"提币"
2. 选择要提的代币 → 输入对方地址
3. 输入金额 → 确认提币
4. 等待链上确认

### 兑换
1. 钱包 Tab → 点"兑换"
2. 选择支付币种和获得币种
3. 输入金额 → 点"获取报价"
4. 确认兑换（通过 OKX DEX 聚合器执行）

## 三、钱包安全

- 私钥由 OKX TEE 保护，任何人（包括平台）都无法获取
- 登录使用邮箱 + 验证码
- 不要在不明网站输入助记词
- 不要相信任何要求转账的私信

## 四、常见问题

### 钱包相关
- "钱包怎么注册" → 对话页选小海豚，输入邮箱创建
- "忘记密码" → 不用密码，用邮箱+验证码登录
- "钱包安全吗" → OKX TEE 保护，私钥不出 TEE
- "到账了吗" → 去钱包 Tab 刷新余额查看

### 交易相关
- "怎么买币" → 钱包 Tab 点"兑换"
- "手续费多少" → X Layer 链免 Gas，其他链实时显示
- "兑换失败" → 检查余额、网络、滑点设置

### 信号相关
- "信号怎么看" → 信号 Tab 查看链上聪明钱动向
- "跟单怎么操作" → 信号页找到感兴趣的，点进去看数据

## 五、安全提醒

- 绝不代用户执行交易
- 充值/提币引导用户去钱包 Tab 操作
- 发现可疑链接/代币提醒用户注意
- 不提供投资建议
