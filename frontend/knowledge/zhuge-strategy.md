# 诸葛策略 知识库

## 一、核心策略

### 策略一：H1 布林带均值回归
- **逻辑**：价格触及布林下轨 → 做多，触及上轨 → 做空，回归中轨止盈
- **参数**：周期 20，标准差 2，1H K线
- **入场**：价格 < 布林下轨 AND HURST < 0.45（震荡市确认）
- **止盈**：布林中轨（SMA20）
- **止损**：入场价下方 1.5×ATR
- **胜率参考**：震荡市 55-65%，趋势市 < 40%（趋势市禁用）

### 策略二：H3 支撑狙击
- **逻辑**：价格回踩 Pivot S1/S2 支撑位 → 做多，反弹 R1/R2 → 做空
- **参数**：传统 Pivot（H/C/L 三点计算），4H 或 日线
- **入场**：价格触及 S1 ± 0.3% AND HURST > 0（有趋势保护）
- **止盈**：R1（做多）/ S1（做空）
- **止损**：S2（做多）/ R2（做空）
- **适用**：趋势行情（HURST > 0.5）

### 策略三：EMA 金叉死叉
- **逻辑**：EMA12 上穿 EMA26 → 做多，下穿 → 做空
- **参数**：EMA(12, 26)，1H/4H K线
- **确认条件**：成交量放大 1.5× + MACD 同向
- **止盈**：1:2 盈亏比（RR=2）
- **止损**：金叉/死叉点反向 2×ATR

### 策略四：成交量突破
- **逻辑**：成交量突增 3×均值 + 价格突破近期高点 → 趋势启动
- **参数**：成交量 MA20 的 3×，价格突破 20 期高点
- **入场**：双条件同时满足
- **止盈**：追踪止损（价格回撤 1.5×ATR 离场）
- **止损**：突破前低

## 二、技术指标解读

### HURST 指数
| 值 | 市场状态 | 策略建议 |
|----|---------|---------|
| > 0.55 | 趋势行情 | 顺势而为，不逆势 |
| 0.45-0.55 | 过渡期 | 观望，等方向明朗 |
| < 0.45 | 震荡行情 | 高抛低吸，用均值回归 |

### EMA 均线
- EMA12 > EMA26 且间距扩大 → 多头趋势加强
- EMA12 < EMA26 且间距扩大 → 空头趋势加强
- 均线缠绕 → 震荡整理

### 布林带
- 带宽收窄 → 即将变盘（关注突破方向）
- 带宽扩张 → 趋势加速
- 价格沿上轨/下轨运行 → 强趋势，不要逆势

### Pivot 支撑阻力
- S1/S2 做多区域，R1/R2 做空区域
- Pivot 线本身有磁吸效应
- 突破 S1/R1 后加速到 S2/R2 的概率 > 60%

## 三、风控体系

### 仓位管理
| 信号强度 | 仓位 | 条件 |
|----------|------|------|
| 强信号 | 10% | 2+ 指标共振（如金叉+成交量+布林带突破） |
| 中信号 | 5% | 单一指标 + HURST 配合 |
| 弱信号 | 0% | 仅满足一个条件或 HURST 矛盾 |

### 止损铁律
- 每单必带止损，最大亏损 ≤ 总仓位的 2%
- 止损不移动（不放大亏损）
- 连续 3 次止损 → 暂停该策略 24h

### 市况切换
- HURST > 0.55 → 用趋势策略（EMA/突破）
- HURST < 0.45 → 用震荡策略（布林带/Pivot）
- 重大新闻前后 1h → 不交易

## 四、多币扫描机制

### 扫描范围
- 默认：BTC, ETH, SOL, BNB, XRP, DOGE, ADA, AVAX（8 币种）
- 可指定：用户说具体币种即可

### 评分标准
| 指标 | 得分 | 权重 |
|------|------|------|
| 有交易信号 | +30 | 30% |
| HURST 状态匹配策略 | +20 | 20% |
| 成交量活跃 | +20 | 20% |
| RR > 2 | +20 | 20% |
| 多指标共振 | +10 | 10% |

### 输出格式
- 按评分排序，Top 3 给出完整分析
- 其余给简述（币种 + 方向 + RR）
- 标注"当前无信号"的币种

## 五、回答指南

### 用户问"分析一下XX"
→ 先报价格 + HURST + 趋势方向
→ 再给支撑阻力位
→ 有信号就报信号（入场/止盈/止损/RR）
→ 没信号就说没信号

### 用户问"有什么交易机会"
→ 跑多币扫描
→ Top 3 完整分析，其余简述
→ 标注当前市况（趋势/震荡）

### 用户问"回测XX"
→ 报收益%、胜率、交易笔数、夏普比
→ 说明回测不代表未来
→ 问用户要不要看持仓

### 用户问"我的持仓怎么样"
→ 报当前持仓列表 + 浮动盈亏
→ 对比入场价给出盈亏分析
→ 不给平仓建议（用户自己决定）
