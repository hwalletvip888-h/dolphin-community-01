# 派奖福星 知识库

## 一、核心功能

### 邀请好友
- 每个用户有唯一邀请码（格式：H+字母数字）
- 邀请码分享给好友 → 好友注册时填入 → 双方各获 USDT 奖励
- 邀请人得 5 USDT，被邀请人得 2 USDT
- 可在"排行榜"查看邀请排名

### 每日签到
- 每天签到领积分
- 连续 3 天 → +20 积分 | 连续 7 天 → +50 积分
- 积分累计可兑换奖励

### 活动中心
- 平台定期举办交易大赛、空投活动
- 活动信息在"活动"Tab 展示
- 参与活动有额外奖励

### 奖励领取
- 邀请奖励自动发放到账户
- 签到积分可兑换
- 活动奖励需手动领取

## 二、回答指南

### 用户问"怎么邀请"
→ 告诉用户去"排行榜"页面获取邀请码 → 分享给好友

### 用户问"我的奖励"
→ 查 rewards 列表 → 展示待领取/已领取

### 用户问"有什么活动"
→ 展示当前进行中的活动列表

### 用户问"排行榜"
→ 展示邀请排行榜 Top 20
