# 链上猎手 知识库

## 一、赚钱路线图谱

### 1. 一级 — 新币狙击
- **入场时机**：PumpFun 内盘 bonding curve 70-90% 时（即将外盘）
- **关键指标**：Dev 历史 Rug 次数 = 0，LP 销毁率 > 90%，前10持仓 < 30%
- **风险红线**：Dev 创建过 >20 个代币且 Rug > 3 次 → 🔴 极高风险
- **出货信号**：Dev 钱包余额突降 50%+ → 立即预警
- **链区别**：Solana 看 PumpFun，BSC 看 Four.meme，ETH 看 Uniswap 新池

### 2. 二级 — 聪明钱跟单
- **跟单策略**：找 30 天内胜率 > 60% 且已实现盈利 > $10K 的地址
- **共振买入**：同一代币被 ≥3 个聪明钱/KOL 地址在 24h 内买入 → 强信号
- **资金验证**：买入金额 < 地址总资产的 5% → 试探仓，不是重仓信号
- **假聪明钱识别**：地址 7 天内创建、交易 < 20 笔、总 PnL 为负 → 可能是假号

### 3. 二级 — 链上套利
- **DEX 价差**：同一代币不同 DEX 价差 > 1% → 可套利（扣除 Gas 后）
- **跨链价差**：同一代币不同链价差 > 3% → 跨链搬砖
- **MEV 保护**：交易必须开 MEV 保护，否则被抢跑

### 4. Meme 季节轮动
- **动物币周期**：DOGE → SHIB → PEPE → WIF → 下一个动物
- **AI 币周期**：跟着 AI 热点走，看 social media 提及量飙升
- **土狗生命周期**：发射 → 拉升（2-6h）→ FOMO（12-24h）→ 出货 → 归零
- **入场窗口**：Meme 币生命周期短，需快进快出

## 二、风控体系

### 安全评分（0-100）
- 🟢 **80-100 安全**：合约开源验证、无后门、LP 锁仓、分布健康
- 🟡 **50-79 注意**：有风险项但可控
- 🔴 **0-49 高风险**：明确不建议参与

### 十大风险指标
| # | 指标 | 阈值 | 含义 |
|---|------|------|------|
| 1 | Dev Rug 历史 | > 0 次 | 开发者此前做过 Rug Pull |
| 2 | 捆绑包占比 | > 30% | 大量代币集中在捆绑地址中 |
| 3 | 狙击手占比 | > 30% | 大量机器人抢跑 |
| 4 | 前10持仓集中度 | > 60% | 少数地址控制大部分供应 |
| 5 | LP 未锁定 | - | 流动性可被撤走 |
| 6 | 合约未开源 | - | 代码无法审计 |
| 7 | 可无限增发 | - | 供应量可被修改 |
| 8 | 买卖税过高 | > 10% | 交易磨损太大 |
| 9 | 钓鱼警告 | > 0 | 地址与已知钓鱼关联 |
| 10 | 假量交易 | > 80% | 交易量由刷量地址制造 |

## 三、链上侦查技巧

### 看地址
- 地址年龄 < 7 天 + 交易 < 20 笔 → 新号，不可信
- 地址只买不卖 + 持仓高度集中 → 可能是项目方自己
- 地址资金来源是 Tornado Cash → 洗钱风险
- 盈利地址突然清仓 → 市场顶部信号

### 看代币
- 持有人快速增长 + 聪明钱买入 → 早期信号
- 交易量激增 + 价格未动 → 即将拉升
- 持有人下降 + 大户出货 → 见顶信号
- 社交提及飙升 + 链上买入确认 → Meme 共振

### 看市场
- Gas 费用突增 → 链上活动激增
- 各链新币发射数量对比 → 热度流向

## 四、赚币策略库

### 策略一：聪明钱跟单
- **原理**：追踪胜率>60%、已实现盈利>$10K的地址，当≥3个聪明钱24h内买同一代币时跟单
- **风控**：单笔≤仓位5%，设止损-15%
- **执行**：信号触发→查代币安全评分>60→确认买入→设止盈止损
- **数据支撑**：onchainos workflow smart-money 逐地址PnL追踪

### 策略二：新币狙击
- **原理**：PumpFun/发射台新币，内盘进度70-90%时入场，外盘开盘5分钟内出货
- **筛选条件**：Dev Rug=0、LP销毁>90%、前10持仓<30%、无捆绑包
- **风控**：单币≤仓位2%，不做长持
- **数据支撑**：OKX memepump tokenList + onchainos token report 安全检查

### 策略三：Meme 共振
- **原理**：社交热度+链上买入同时爆发时追入，吃情绪溢价
- **入场信号**：社交提及量飙升>500% AND 链上买入tx数>100/h AND 聪明钱进场
- **出场信号**：社交热度见顶回落 OR 大户开始出货 OR 持有24h
- **风控**：Meme生命周期<72h，80%归零，只拿利润参与
- **数据支撑**：OKX Hot Tokens social score + onchainos workflow smart-money

### 策略四：链上套利
- **原理**：同一代币不同DEX价差>1%时套利
- **执行**：低价DEX买入→高价DEX卖出，扣除Gas后仍有利润
- **限制**：需快速执行（MEV保护），大额需分拆
- **数据支撑**：OKX DEX Aggregator quote 自动比价

### 策略五：空投交互
- **原理**：识别未发币协议，低成本交互获得空投资格
- **筛选**：高TVL未发币协议、测试网活动、Galxe/Zealy任务
- **风控**：只用新钱包、不暴露主钱包

### 策略六：Launchpad 打新
- **原理**：OKX Jumpstart/Binance Launchpad 等IEO平台打新
- **执行**：持有平台币获得额度→新币上线快进快出
- **数据支撑**：onchainos workflow new-tokens 监控新发射

## 五、实战教训（来自 Codex 模拟交易系统真实数据）

### 教训一：聪明钱信号有延迟，人比 AI 快
- **Codex 数据**: 378 个原始信号 → 0 笔交易 → 93% 被"卖出比>35%"拦截
- **含义**: 信号到达时，聪明钱已经在出货了。REST API 轮询比人类慢 30-120 秒
- **对策**: 
  - 不要等信号，要预判信号——看同一地址的历史交易模式
  - WebSocket 流 > REST 轮询 > 手工查询
  - 聪明钱进场是信号，聪明钱**开始出货**是警报

### 教训二：70% 的失败来自基础设施
- **Codex 数据**: 23 轮扫描中 16 轮失败（69.6%），原因: API 限流/区域限制/认证失效
- **含义**: 策略再好在运行故障面前都白搭
- **对策**:
  - API 多 Key 轮换（避免单 Key 限流）
  - 多区域部署（避免区域限制）
  - 失败重试要有退避策略

### 教训三：信号过滤是双刃剑
- **Codex 数据**: 卖出比>35% 过滤了 93/108 条信号，金额<$500 过滤了 12 条，黑名单过滤了 4 条
- **含义**: 过滤太严 → 没有交易 → 资金闲置。过滤太松 → 亏损
- **调整建议**:
  - 卖出比阈值从 35% 提高到 50%（给信号更多窗口）
  - 金额阈值从 $500 降到 $200（小仓位试错）
  - 7 个黑名单钱包持续更新，443 个观察地址追踪

### 教训四：无交易也会亏钱
- **Codex 数据**: 无交易情况下权益下跌 7.5%（$242.95）来自持仓估值变化
- **含义**: 不开仓也是一种风险——通胀/机会成本/已有持仓下跌
- **对策**: 没有好机会就配置稳定币理财（DeFi 产品），不让资金闲置

### 教训五：链上老手的操作模式
- **聪明钱特征**: 443 个观察地址 → 7 个被拉黑（1.6%）
- **假聪明钱模式**: 反复做同一个币（对倒/刷量）、新地址大额进出（可能是项目方）
- **真聪明钱模式**: 分散多币种、小额试探→确认→加仓、快进快出
- **人类狙击手的操作**: 
  - 盯着聪明钱的第一次小额试探仓，在加仓前抢先
  - 用 WebSocket 实时监控聪明钱地址的 tx
  - 聪明钱出货前 30 秒先行离场

## 六、策略信号系统

### 信号合成公式

买入信号 = 聪明钱共振 × 安全评分 × 时机判断

**指标权重：**

| 一级指标 | 权重 | 得分条件 |
|----------|------|---------|
| 聪明钱共振 | 40% | ≥3 个聪明钱/KOL 24h 内买入 = 40 分 |
| 安全评分 | 35% | 风险等级 LOW = 35 分，MEDIUM = 15 分，HIGH = 0 分 |
| Dev 可信度 | 15% | Rug 历史 = 0 次 = 15 分，>0 次 = 0 分 |
| LP 锁仓 | 10% | 销毁率 > 90% = 10 分，锁仓中 = 5 分，未锁定 = 0 分 |

**买入决策阈值：**
- 总分 ≥ 70 → 🟢 强信号，可开仓
- 总分 50-69 → 🟡 中等信号，小仓试探（≤ 本金的 2%）
- 总分 < 50 → 🔴 不进场

### 止损止盈规则

| 策略类型 | 止损 | 止盈 | 适用场景 |
|----------|------|------|---------|
| 聪明钱跟单 | -15% | +30% | 二级市场跟单 |
| 新币狙击 | -10% | +50%（限时 5 分钟内） | 一级市场打新 |
| Meme 共振 | -20% | +100%（或持有 <24h） | Meme 情绪交易 |
| 保守策略 | -8% | +15% | 蓝筹/主流币 |

**止损优先级：**
1. Dev 钱包余额突降 50% → 无条件清仓（覆盖所有止损）
2. 卖出比突升 > 50% → 立即减半仓
3. 价格触及止损线 → 全平

### 本金管理

| 总本金 | 单币仓位上限 | 同时持仓上限 | 预留现金 |
|--------|------------|------------|---------|
| < $1,000 | 5%（$50） | 3 个币 | 30% |
| $1,000-$10,000 | 3%（$300） | 5 个币 | 25% |
| > $10,000 | 2%（$200） | 8 个币 | 20% |

**资金分配原则：**
- 永远保留 ≥ 20% 现金（应对机会或补仓）
- 同一赛道（如 Meme）不超过总仓位的 30%
- 盈利后先提利润，用利润滚仓，不动本金
- 连续 3 笔亏损 → 暂停交易 24h，复盘后再战

## 七、回答指南

### 用户问"有什么机会"
→ 综合展示：热门代币 Top 5 + 聪明钱共振信号 + 新发射潜力币
→ 每个标的标注风险等级
→ 不说"推荐"，说"值得关注"

### 用户问"这个币能买吗"
→ 先给安全评分 + 风险项
→ 再给聪明钱动向 + 持仓分布
→ 最后说"以上是客观数据，是否投资请自行判断"
→ 绝不回答"能买"或"不能买"

### 用户问"帮我盯着"
→ 提取监控目标（代币/地址）
→ 说明当前监控能力（需结合 App 推送）
→ 告知限制：实时监控需使用 App 通知功能

### 用户给了一个地址
→ 先查资产 + PnL
→ 分析交易风格（短线/长持）
→ 给出信誉评级
